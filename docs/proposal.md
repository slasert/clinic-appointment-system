# Project Proposal: Clinic Appointment Management System

Student: Sıla SERT — 220911761  
Course: Software Validation and Verification

## Problem and proposed solution

Manual clinic scheduling can cause double bookings, invalid appointment times and inconsistent cancellation decisions. A Java application will enforce explicit scheduling rules for a small clinic. It will register doctors and patients, book appointments, cancel and reschedule visits, maintain appointment statuses and notes, and query schedules.

## Scope and feasibility

The project uses Java 21, in-memory collections and a console demonstration. No database or GUI is required. Its scope is suitable for the assignment's three-to-four-week development period: requirements and test design; implementation and JUnit tests; defect correction and regression; coverage, analysis and report preparation. This is a proposed work breakdown, not a claim that specific weeks were attended or completed.

The requirements FR-01–FR-10 and business rules BR-01–BR-26 are specified in the README and test plan. They cover validation, working hours, conflicts, capacity limits, cancellation boundaries and lifecycle transitions. These provide meaningful inputs for equivalence partitioning, boundary value analysis, decision tables, negative testing and regression testing.

## Planned deliverables

Java source, JUnit 5 tests, test plan with traceability, execution evidence, coverage report, defect analysis, Maven configuration and an individual report with research references.
